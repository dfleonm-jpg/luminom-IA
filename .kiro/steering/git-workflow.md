# Flujo de Git para este proyecto

- Commitear y subir SIEMPRE directo a `main`. No crear ramas intermedias ni Pull Requests.
- Tras cada conjunto de cambios: `git add`, `git commit` con mensaje claro, y `git push origin main`.
- Esta es una preferencia explícita del dueño del repositorio (confirmada en sesión).
